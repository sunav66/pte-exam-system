# PTE 考试系统 — 获客与传播方案

目标：以最低成本找到最适合的受众（PTE 考生），用对的渠道触达，并设计裂变让已付费用户帮你传播。
产品卖点（传播素材核心）：¥6.6 永久激活 / 离线可用 / AI 批改（口语写作）/ 机经题库 / 比机构便宜几百倍。

## 三、转化路径（适配"个人微信收款 + 手动发链接"）

```
内容曝光 → 落地页(下载/加微信) → 付款(个人微信码) → 卖家发激活码或生成器链接 → 激活使用
                                      ↑                                  ↓
                              朋友圈/群分享 ←———— 裂变奖励(晒分/转介绍送码) ←———— 满意用户
```

落地页必须同时有：**网盘下载 + 直链下载 + 微信付款码 + 加群入口**。

## 四、裂变/传播机制（让买家帮你拉新）

1. **老带新送码**：买家转发指定海报到朋友圈/群，截图给微信，奖励 1 个免费激活码（你用 `tools/gen_offline_code.py` 现生成，成本 0）。
2. **晒分返现**：出分截图发小红书/@你，返 ¥3~6 或送码 → 真实出分内容是最好广告。
3. **资料包裂变**：关注/转发领「PTE 最新机经包」→ 引流到微信，再转化付费。
4. **代理机制**：中介拿批量码（你的码池），自行加价卖，你只管供货。

> 注意：买方生成器每安装限 1 码，不能用于"送朋友码"；奖励码由你从后台生成发放。
